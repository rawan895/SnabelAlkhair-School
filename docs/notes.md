# Project Notes

## Docker Experience

The project uses Docker to containerize the React frontend and NestJS backend.

Docker Compose is used to build and run both services together.

During the project, I learned how to work with Dockerfiles, images, containers, ports, and multi-stage builds.

## Git and GitHub Lessons

The most important lesson I learned was using Git commits to save project changes.

I learned that:
- Each commit records a specific set of changes.
- Clear commit messages make project history easier to understand.
- Git helps track changes and return to previous versions.
- GitHub provides an online repository for sharing and managing project code.
